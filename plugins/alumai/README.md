# AlumAI · 网页账号图文中转

前台 `/ai`，后台 `/ai/admin`。支持文字与图片双向中转：网站将问题和图片交给服务器上的个人 Chromium，程序通过可见网页输入区与文件上传控件提交一次，再保存本次回答的文字、图片与排版。**不使用 OpenAI API、非公开 ChatGPT 接口、共享账号或代填密码。** 用户必须使用自己的 ChatGPT 网页账号。

回答提供“原貌 / 排版 / 文字”三种视图。“原貌”是回答区域的静态PNG快照，保留字体、图片、公式、颜色及排列，而不是整屏远程桌面；不能点击其中的网页控件。“排版”保留安全的标题、列表、表格、代码、链接与图片，支持选择文字，但不加载提供商CSS，因此不承诺逐像素一致。图片在服务器浏览器中按可见效果截图保存，不代表提供商原始高分辨率文件；动画、视频和交互组件不作原样交互承诺。部分资源失败会明确提示，不静默宣称完整。

这是实验性网页适配，不是 OpenAI 提供的受支持接口。目前只适配 `https://chatgpt.com/`；后台可以添加更多 AI 网站入口，但添加网址不等于实现该网站的文字中转。网页结构、账号限制或服务规则变化可能使适配停止工作。请确认目标服务允许你的使用方式及服务器所在地区；本插件不绕过地区、验证或用量限制。

## 安装或从远程桌面版升级

需要 Ubuntu/Debian、systemd、Node.js 20+、至少4 GB内存和足够磁盘（建议空闲10 GB以上），并能下载 Docker 镜像、访问目标网站。首次下载镜像和中文字体可能耗时较长。

```bash
cd /opt/alum4k
sudo git pull --ff-only
sudo bash scripts/update-linux.sh
sudo bash scripts/setup-ai-linux.sh
```

**本次升级必须重新运行 `setup-ai-linux.sh`**，以更新私有运行服务、重建带本机调试桥的浏览器镜像。仅更新网站代码不足以启用文字中转。脚本不会修改网站1023端口、域名或HTTPS设置，也不会删除个人浏览器资料卷。

脚本在缺少 Docker 时通过 apt 安装 docker.io，构建 `alumai-browser:1`，安装只监听 `127.0.0.1:5188` 的 `alumai-runtime` 服务，并备份、更新现有 `.env`，不打印凭据。运行服务位于 root 私有的 `/opt/alumai-runtime/`，网站进程不需要 Docker socket 或 docker 用户组权限。以后运行服务或镜像变更仍需重新运行安装脚本。

## 使用流程

1. 在 `/ai/admin` 检查组件状态。管理员默认可用，其他账号必须按已有用户名明确授权；只授权完全可信的人。
2. 在 `/ai` 选择 ChatGPT，点击“账号登录 / 验证”。用户本人在此辅助窗口完成网页登录、密码、多因素验证或验证码，程序不代操作认证步骤。
3. 关闭辅助窗口，点击“检查网页连接”，确认网页账号可用后发送文字或图片问题。图片仅支持PNG、JPEG、WebP，每次最多3张，每张3 MB，合计6 MB。关闭窗口只断开画面，不清除服务器上的本人登录状态。
4. 对话可继续、停止、复制、导出或删除本地记录。删除 AlumAI 记录不会删除 ChatGPT 官网保存的对话。

登录失效、验证码、网页限流、未发送草稿、无法确认已登录或网页结构变化时停止。每人同时仅处理一个问题。网页自动化只有一次发送动作，不会自动重试结果不确定的问题；请求标识防止网络重试重复提交。服务器重启后的未完成问题标记为中断，不会自动重放历史问题。

新回答先逐步返回文字，完成后保存图片、原貌和安全排版；只有确认属于本次问题且网页显示完成才标记为完整。超时或取消后的部分文字有明确状态。原貌尺寸最多1800×16000且不超过2800万像素，超长回答会回退为可恢复的排版并提示，排版独立图片最多12张。无法恢复官网会话地址时要求新建对话，不会重发历史问题伪造上下文。

## 资源与隐私

- 默认同时运行1个个人浏览器。主机管理员可在 `/etc/alumai/runtime.env` 设置 `ALUMAI_MAX_BROWSERS=1`（1到10）并重启 `alumai-runtime`，按服务器资源调整。
- 每个浏览器限制2 GB内存、1.5 CPU、512个进程和512 MB共享内存。每个网站用户名使用独立容器与资料卷，不共用 ChatGPT 登录。
- 浏览器空闲15分钟后回收，个人资料保留。文字任务运行时续租；辅助登录窗口每20秒续租。退出网站登录会关闭本人浏览器并取消文字任务；关闭浏览器仍保留资料卷中的登录状态。
- 配置位于 `data/ai/settings.json`，有原子写入、修订检测与 `.bak`；对话明文保存在 `data/ai/chats/<账号哈希>.json`，有原子写入及权限隔离。每人最多50个对话，每个100条消息，问题8000字，回答60000字，总保存文字约200万字。
- 凭据位于 `.env` 和 `/etc/alumai/runtime.env`。浏览器登录、历史及默认路径下载文件位于 Docker 卷 `alumai-profile-<账号哈希>`。所有这些文件均不得提交 Git 或公开分享。主机管理员可访问私有数据，磁盘不保证加密，应保护主机与备份。
- 网站更新会备份 data 和 .env，**不备份 Docker 资料卷**。迁移登录状态需在浏览器停止后私下备份卷，目标网站仍可能要求重新验证。
- 上传图片、回答图片及快照在 `data/ai/assets/<账号哈希>/<对话ID>/` 私有保存，按账号和所属对话验证读取，每人图片上限200 MB。删除本地对话会清理该对话图片。图片不使用公共网址或URL登录令牌；前台鉴权获取后以临时blob显示，退出或卸载时回收。原貌截图和图片同样可能含敏感信息，需保护备份。
- 辅助窗口支持手动中文剪贴板，不自动读取本机剪贴板。文本通过 UTF-8 stdin 传入本人容器，不放进 Docker 命令参数。界面不执行回答中的原始HTML、脚本或远程CSS；图片来自服务器已登录浏览器的可见渲染，前台不会直接请求第三方图片地址。

## 安全边界

网站只根据当前已认证用户名读写私有对话；不接受客户端指定其他所有者。后台配置停用工具、撤销授权或关闭模块会取消相关任务。CDP 调试地址与服务凭据不返回前端。调试连接和VNC均只发布到服务器回环地址，辅助窗口还要求当前账号、短期HttpOnly/SameSite=Strict Cookie与同源WebSocket校验；HTTPS下Cookie增加Secure。上游VNC不会收到网站JWT或Cookie。

**不要放行5188、4444、5900、7900、9222或9223，也不要将VNC、CDP或本机调试端口反代成公共入口。** 只通过已有HTTPS网站使用。主机上其他具备本地访问权限的进程仍可能访问回环调试端口，浏览器主机必须可信。

容器无 privileged、Docker socket 或主机目录挂载，移除 Linux capabilities 并限制资源；Chromium 为非root运行，但带 `--no-sandbox`，Docker 是主要隔离边界，**不是强多租户沙箱**。浏览器可访问服务器网络，网址公开HTTPS校验不等于完整网络出口隔离。不要向陌生注册用户开放，建议独立无敏感内网的浏览器主机。没有下载磁盘配额，需监控磁盘空间。

## 排错

```bash
sudo systemctl status alumai-runtime --no-pager
sudo journalctl -u alumai-runtime -n 80 --no-pager
sudo docker ps --filter label=alumai.managed=1
```

提示组件未安装或需要升级：执行安装脚本并检查服务。提示登录失效或验证：本人打开辅助窗口处理。目标网站打不开：检查服务器网络、服务地区及账号状态。结构变化：等待适配修复，不会自动绕过验证。不要公开包含登录信息、对话内容或凭据的截图和日志。

主机管理员可通过 `ALUMAI_BASE_IMAGE` 指定经审查的 Selenium standalone-chromium 标签后重跑安装脚本。默认固定到 `155.0-chromedriver-155.0-grid-4.50.0-20261010`，不自动拉取陌生镜像。
